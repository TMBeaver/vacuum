Vacuum 0.3.0

The robot is the interface: press its physical power, home, mop, clock, hatch, dock or scanner controls. Inspect the thicker 3D body by dragging it. Graphite and porcelain themes retain the scene and camera. Typography uses Bahnschrift and Segoe UI Variable; file and memory sizes use MB, GB and TB.

The taskbar companion drives looping passes with rounded turns beside Start, with dust or blue water trails. It passes clicks through and relocates after display-layout changes. Keyboard panels contain focus and return it to the original control when closed.

Real file scans fill a reviewable reference bin. Explicit confirmed emptying sends selected files to Windows Recycle Bin. Daily rounds never empty the bin. Closed Chrome/Edge caches are guarded independently; cookies, logins, sessions, extensions and site storage remain protected. Old Downloads require explicit review.

Selected-file NTFS compression verifies contents and actual allocation. Undo preserves legitimate edits to the same file and survives restart. A durable journal supports interrupted-operation recovery. Quit waits for recycling/compression/performance actions to settle. Recycling is not reported as drive space reclaimed.

The scanner control opens local CPU, memory, app/process and listening-port review. Normal app close respects refusal; stopping a windowless task requires separate confirmation and native identity checks. Ports are checked again afterward. Daily cleaning never closes user apps automatically.

Wet mode uses Microsoft Defender against temporary files and Downloads without requested remediation. Completed, failed, unavailable and cancelled scans have separate honest results. It is not a full-device security assessment.

Validation includes 71 tests and native checks against the installed Windows app: interactive WebGL, both themes, looping motion, recycling/restoration, compression/Undo/recovery, keyboard, display events, startup/scheduling, 50,000-reference review, performance fixtures, scan errors and real current-user installer upgrades. Earlier installs and synthetic fixtures were retained. No personal file was permanently removed and no user app was closed.

The private Windows x64 installer is unsigned. Real OS sign-out/reboot and physical monitor reconfiguration were not performed; native startup/approval, background scheduling, resume listeners and display events were exercised directly. See `release-audit-0.3.0.md` for exact evidence and limits.
